# Contributing

This repository contains the source code, personal essays, software archives, and configurations for my personal website (<https://sw.szymon-wilczek.me>).

## Policy on Contributions

Because this repository represents my personal digital garden and publishing space:

- **Pull requests for new features, personal preferences, or design overhauls are not accepted.**
- **Bug reports and typo corrections** are welcome via [GitHub Issues](https://github.com/szymonwilczek/sw.szymon-wilczek.me/issues) or [Pull Requests](https://github.com/szymonwilczek/sw.szymon-wilczek.me/pulls). If you discover a broken link, rendering glitch, broken build pipeline, or typographic error, feel free to submit an issue or a PR.

Thank you for understanding and respecting these boundaries.
